# AI 产品评测作品集 · 罗千钧

2025.07 至今，我为「袋鼠帝AI客栈」公众号撰写的 AI 产品评测作品清单。

**说明**：以下所有文章均由我本人独立完成研究与写作（产品设计实测任务、跑真实用例、记录证据、成稿），并已全部公开发表于「袋鼠帝AI客栈」公众号，主理人负责最后的文字润色。本仓库只收录作品清单与数据，不收录全文（版权归公众号）。

**总账**：35 份评测文档 → 成稿约 24 篇 · 累计 10.8 万字 · 684 张实测截图 · 覆盖 20+ 家产品

**覆盖面**（按产品形态演进）：

1. 聊天时代——豆包、Kimi、通义 Qwen、MiniMax M2.1 / M2.5、美团 LongCat、阶跃 Step3.7、GLM-4.5 Air、DeepSeek V4
2. 智能体——Kimi OK_Computer、Doubao Code、Trae 与 Trae SOLO、腾讯云智能体平台、秒哒、腾讯 Marvis、百度 DuMate
3. Claw 系——skyclaw、OpenClacky、clawdbot
4. 个人智能体——蚂蚁灵光（两轮长测）

**我的评测方法论**（全部自创、可在文章中验证）：

1. **场景化验证**——从普通人的真实困境切入设计任务（学生改论文、股民入场、健身者被 AI 管理），给真实提示词，观察全过程再下结论，从不空谈参数。
2. **逻辑陷阱法**——故意给模型挖坑，探它的能力斩杀线在哪。
3. **AI 评 AI**——让另一个模型当裁判，交叉验证输出质量。
4. **官方 case 变形**——官方 demo 全部改造再用，测真实场景下的表现。
5. **真实世界回查**——结论拿到现实里核实（民法典原文、权威数据源），专治幻觉。
6. **证据链**——每篇保留版本号、耗时记录、截图录屏、第三方复核，结论可验证。

## 数字背后

这批评测不是「体验报告」堆料。每篇都遵循同一个流程：设计真实任务 → 记录全过程 → 交叉验证 → 迭代成稿。迭代是常态——腾讯 Marvis 写了三轮、蚂蚁灵光 2.0 写了五轮，直到终稿能直接发表为止。这正是 AI 产品经理的日常：拿到一个模型能力，把它翻译成普通用户能感知、能验证、能复现的体验。
